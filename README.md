# Автоматизированная система визуализации архитектуры распределенных приложений

- `prototype/` - распределенное приложение для анализа и эталонная модель
- `archviz/` - экстрактор архитектурной модели и загрузчик в Neo4j
- `docs/` - правила сопоставления фактов из артефактов с элементами модели
